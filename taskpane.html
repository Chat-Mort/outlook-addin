Shortcuts

Give a template a shortcut name in its edit form, then type ##name anywhere (in another template, or directly in an open draft) to pull in that template's content. Used in a subject, it pulls the referenced template's subject; used in a body, its body. Nested shortcuts work (up to 5 levels deep). The ⚡ menu's "Shortcuts" entry lists every shortcut you've defined, so you don't have to remember exact spelling.

Using a template

Click anywhere on a template card: it inserts into an already-open draft, or creates a brand new email if you're browsing the inbox. The ✎ and 🗑 icons edit or delete without triggering insertion; ⧉ duplicates a template.

Attachments

Mark a stored attachment "Final document" to have it attached automatically wherever possible. Otherwise it's treated as a blank placeholder: you'll get a reminder with a "Download blank" button and an "Import final" button to attach your real file instead. New emails created from the inbox (separate window) can only offer the download — nothing can be auto-attached there, that's an Outlook API limitation.

Characters

The Characters tab is a searchable palette of hard-to-type characters: superscripts and subscripts, accents, fractions, French typographic spaces, math, currency, arrows, symbols. Search by name, keyword (French works too: “exposant”, “flèche”) or code. A click inserts the character at the cursor of the open draft, or copies it when no draft is open (the drop-down at the top switches between insert and copy). Hover a character to see how to type it by hand: Alt + code on the numeric keypad, or hex code then Alt + X in the classic Outlook compose window (Word engine; it doesn't work in Outlook on the web). The converter turns text into superscript or subscript, e.g. 1er → 1ᵉʳ. To insert a character into a template, use copy mode and paste.

Storage

Template text is synced to your mailbox (RoamingSettings — works across devices signed into the same account). The directory, attachments, and code history stay local to this browser/device only (the directory was moved off synced storage after a sync failure risked corrupting it alongside templates — see the Changelog). Use Export/Import (⬇/⬆) for a manual backup of either.
